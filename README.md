# 🛍️ Product Catalog

A modern Product Catalog application built with **Next.js 16**, **React 19**, **TypeScript**, **Tailwind CSS**, and **Axios**.

## 🚀 Features

- 📦 Product Listing
- 🔍 Search Products
- 🏷 Category Filter
- 📊 Sort by Price & Rating
- 📄 Product Details
- ➕ Create Product
- ✏️ Edit Product
- 🗑 Delete Product
- 📑 Pagination
- ⚡ Loading State
- ❌ Error State
- 📭 Empty State
- 📱 Responsive Design

---

## 🛠 Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Axios

## 📦 Installation

```bash
git clone <repository-url>

cd product_catalog_assesment

npm install

npm run dev
```

Application runs on:

```
http://localhost:3000
```
