# Product Catalog

A Product Catalog application built using Next.js, React, TypeScript and Tailwind CSS.

## Features

- Product Listing
- Product Details
- Search Products
- Category Filter
- Sorting
- Pagination
- Create Product
- Edit Product
- Delete Product
- Responsive Design

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Axios

## Installation

```bash
npm install
npm run dev
